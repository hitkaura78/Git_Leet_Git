LC Sync

Sync every Accepted LeetCode submission directly to GitHub.

Setup Checklist

  1. Create a repository on GitHub (make sure to initialize it with a README.md or at least 1 commit).
  2. Generate a GitHub token at github.com > Settings > Developer Settings > Personal access tokens.
  3. Grant permissions: Repository permissions > Contents: Read and write on your solutions repo.
  4. Click Test Connection above to verify.
